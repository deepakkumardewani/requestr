# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

1. **Preferred:** use GitHub private vulnerability reporting. Go to the repository's **Security** tab and choose **Report a vulnerability** (a private security advisory).
2. **Fallback:** email kumard8308887772@gmail.com with a description, reproduction steps and the affected version.

We aim to acknowledge reports within a few days and will keep you updated until the issue is resolved. Please allow a reasonable disclosure window before publishing details.

## Scope

Requestr runs in the browser and keeps request data on your device. Reports about cross-site scripting, unsafe handling of imported data, encrypted sharing, or leaks of request content are especially welcome.
