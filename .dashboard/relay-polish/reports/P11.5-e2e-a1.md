## Implementation Details

### Axe Pattern Reused
Copied the axe helper pattern from `relay-improvements-a11y-axe.spec.ts`:
- `scanElements()` - Scans specified DOM selectors with AxeBuilder
- `scanDock()` - Scans the relay dock element
- `scanDockWithElement()` - Scans dock plus an additional element (menu, popover, etc.)
- Filters violations to only report "serious" or "critical" impacts
- Guards against vacuous scans with `expect(passes.length).toBeGreaterThan(0)`

### Test Features
- Uses `seededPage` fixture with proper test isolation
- Each test sets up its own state (opens routes, seeds threads, etc.)
- No explicit waits (`waitForTimeout`); relies on web-first assertions
- Proper animation settlement with `await expect(popover).toHaveCSS("opacity", "1")`
- Multi-iteration test (scenario 6) iterates through all three permission modes in one test

### Test Data Setup
- Uses `openWithRoutes()` and `installRelayRoutes()` for mocking Relay API
- Uses `putThreads()` to seed conversation threads in IndexedDB
- Uses localStorage to set permission modes in scenario 6
- Uses viewport manipulation (`dragDockToWidth`) for responsive testing
