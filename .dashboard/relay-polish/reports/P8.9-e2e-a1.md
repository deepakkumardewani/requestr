## Behavior Changes

The launcher has a different UX from the old picker:

| Feature | Old Picker | New Launcher |
|---------|-----------|--------------|
| Root view | Shows "Current tab" and all requests | Shows Recent, Attach sections, Actions |
| Request selection | Direct search in root view | Click "request" row, then search in list view |
| Esc behavior | Close from any view | In list view: step back to root; from root: close |
| Focus after close | Varies by context | Always focuses the trigger ("+" button) |
