**Fixtures and helpers used:**
- `installRelayRoutes()` - hermetic mock Relay chat endpoint
- `startRelayGate()` - manual chunk delivery for order verification
- `openRelay()`, `sendMessage()` - e2e helpers
- `relayE2eHelpers.ts` - Relay dock interaction utilities

**Notable test techniques:**
1. **Order verification**: Tests 01-03, 06 use gated responses to push chunks sequentially, then verify order via `document.querySelector` and `compareDocumentPosition`
2. **Clipboard mocking**: Test 04 grants clipboard permissions and mocks `navigator.clipboard.writeText` to capture copied text
3. **DOM stability**: Test 07 marks DOM elements with unique IDs to verify earlier blocks aren't unmounted during streaming
4. **Message settlement**: Tests wait for `.toBeVisible()` on action buttons, which only appear when messages are fully settled (not streaming)
