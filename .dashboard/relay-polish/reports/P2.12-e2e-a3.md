## Failing Tests (3/11)

### SHELL-05: Tooltip keycaps (timeout issue)
**Error**: Tooltip locator with `.filter({ has: locator('kbd:text-is("Shift")') })` returns 0 elements.
**Status**: Locator syntax may not be supported; simpler selectors (awaiting first tooltip, checking for keycaps) work for hover/focus detection but keycap matching strategy needs refinement.
**Fix needed**: Use `:visible` pseudo-class or iterate tooltip array to find keycaps; or use Playwright's built-in `toContainText` on tooltip element.

### SHELL-10: Shortcuts dialog row keycaps (empty array)
**Error**: `newRelayChatRow.locator('kbd').allTextContents()` returns `[]`.
**Root cause**: The row may not have `<kbd>` child elements; keycaps may be nested deeper or use different markup.
**Fix needed**: Inspect actual DOM structure of the KeyboardShortcutsModal row; update selector to match actual structure (e.g., `.locator('text=/⌘|Ctrl/').first()` or deeper nesting).

### SHELL-11: Failed chunk + console guard
**Errors**: 
1. After route abort, toggle not visible on second click
2. Console guard fails: pageerror "Failed to load chunk RelayDockWithMessages_tsx"
**Root cause**: 
- When chunk fails, the Relay dock may not render at all (dynamic import failure)
- The `page.on("pageerror", () => {})` handler registers but doesn't prevent the guard from catching the error

**Fix needed**: 
- Either: Wrap test in a fixture that suppresses/expects this specific error
- Or: Check whether the toggle persists when chunk fails (may be an app bug: toggle might unmount with dock)
- Or: Use `test.fail()` if this exposes an app regression
