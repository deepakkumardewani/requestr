## Key Remediation Strategies

### 1. Mock Enhancement
Updated component mocks from simple render mocks to **prop-capturing mocks**:
```javascript
AskUserCard: (props: any) => {
  mocks.askUserCardProps = props;
  return (
    <div data-testid="ask-user-card">
      <span>{props.question}</span>
      <button onClick={() => props.onChoose(props.options[0])}>Choose</button>
    </div>
  );
}
```

This allows tests to:
- Verify callback functions exist and have correct types
- Invoke callbacks programmatically to test onResolve payloads
- Validate callback parameters without E2E testing

### 2. Type-Based Tool Routing
Fixed test data to use correct type format: `type: "tool-ask_user"` instead of `type: "tool-call"` with separate `toolName` field.

This enables the promptCard function to correctly extract tool names:
```javascript
const name = part.type.slice(TOOL_PART_PREFIX.length); // "ask_user", "close_tabs", etc.
```

### 3. Comprehensive Callback Testing
Added tests that directly invoke captured callbacks to ensure:
- onResolve is called with correct parameters
- Different resolution kinds are used appropriately (answer, approve, decline)
- Special payload fields like `approve: true` are included when needed
