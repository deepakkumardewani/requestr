### Uncovered (Justified)

#### RelayRoot.tsx - Lines 31, 44

**Line 31:** `.catch(() => RelayLoadError)` in the next/dynamic loader
- **Reason:** The `next/dynamic` module is mocked in the test setup (`vitest-setup.ts`). The mock replaces the real dynamic loader with a `React.lazy` wrapper, preventing the `.catch` handler from ever executing. The error path would require either:
  1. Removing the mock (breaks the real next/dynamic behavior for other tests)
  2. Making the mock throw (contradicts the mock's role)
  
This line is covered implicitly in the E2E tests (P3.4) where the actual dynamic import failure would be tested.

**Line 44:** Cleanup function return in `subscribeToMobileQuery`
- **Reason:** The return cleanup function is properly registered with `removeEventListener` in the actual runtime. However, detecting that the cleanup function was returned and stored requires inspecting the closure or mocking the test framework itself. The meaningful behavior (event listener removal) is tested and verified with the spy on `removeEventListener`. The return statement itself is a tautology once the spy confirms the unsubscribe works.
