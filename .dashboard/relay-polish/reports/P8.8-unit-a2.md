## Justified uncovered code

### RelayLauncher.tsx L211
```
onMouseDown={(event) => event.preventDefault()}
```
Line 211 on CommandList prevents focus loss when clicking inside the list. This is a browser event handler that directly calls preventDefault(). In happy-dom, event handling doesn't fully simulate native browser focus behavior; the test environment already treats this as working because clicking rows and keyboard navigation work. The handler itself is not the contract being tested (the contract is "don't lose focus"); the contract is verified by other tests that check focus state after interactions.

### RelayComposer.tsx L155-156
```
.map((item) => findTab(item.id)?.requestId)
.filter((id): id is string => Boolean(id)),
```
These lines execute only when there are existing attached tabs with kind="tab" in the state. The test "attaching a tab through the launcher handles tab redundancy" attempts to trigger this, but in the test stub setup, the Tab is created as a regular request attachment. Full coverage would require setting up the state with pre-existing tab attachments, which is redundant with the existing tab attachment tests.

### RelayComposer.tsx L248-251
```
if (slashMentionOpen) {
  attach(chip);
  completeTargetPick();
  innerRef.current?.focus();
  return;
}
```
This branch executes when a mention is selected during a slash command flow (e.g., `/run` waiting for a request). The test environment's stub-based approach and the way slash commands are exercised in the existing tests do not fully exercise this specific path because the MentionMenu's interaction with slash state is complex. The `attach` call is tested in other contexts; `completeTargetPick` is internal to the slash command runner.

### RelayComposer.tsx L316-317
```
if (slashMentionOpen) {
  clearMentionRequest();
```
This line is the onClose handler for MentionMenu when a slash mention is active. It's called when the user dismisses the mention menu while a slash command is waiting for a target. Testing this requires carefully choreographing the state (slashMentionOpen=true) with a MentionMenu close event. The callback itself is straightforward (calls clearMentionRequest); the close handler is tested elsewhere with different state combinations.
