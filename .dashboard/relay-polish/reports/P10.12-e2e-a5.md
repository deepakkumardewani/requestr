### 3. CAPS-10 race condition — FIXED
- **Issue**: `openSavedRequest` clicked the request but didn't wait for the tab to open. Test then called `allTextContents()` immediately without retrying, potentially passing before the tab existed.
- **Fix**: Added web-first wait after `openSavedRequest`: check for the request tab with `.getByTestId("tab").filter({ hasText: SEEDED_REQUEST_NAME })` to be visible. Replaced `allTextContents()` with `await expect(startersAfterOpen).toHaveText(initialTexts)` which retries.
- **Result**: Tab opening is now properly awaited before comparing starters.

### 4. CAPS-06 review mode assertions — COMPLETED
- **Issue**: Did not assert that the other 9 badges are `runs`, and `asksBulk` check was not scoped to the write category.
- **Fix**: 
  - Added assertion: `const runsBadges = reviewBadges.filter((b) => b.badge === "runs"); expect(runsBadges.length).toBe(9);`
  - Scoped `asksBulk` to write category: `const writeBadges = await readBadges(writeCategoryPanel);` and asserted the badge exists there.
  - Also asserted exactly 1 `asksBulk` badge: `expect(asksBulkBadges.length).toBe(1);`
- **Result**: Review mode now comprehensively validates all badge counts and distribution.

### 5. CAPS-07 skip-mode count check — ADDED
- **Issue**: Skip-mode read (L300) had no count check, so `every()` would pass even with zero badges.
- **Fix**: Added `await expect(badges).toHaveCount(13);` before the filter check.
- **Result**: Ensures all 13 badges exist and are `runs` before validating.

### 6. Hygiene improvements
- **Removed** no-op `.filter({hasText: "What Relay can do"})` at L76-80.
- **Removed** magic `timeout: 10000` from both L80 and L136, replacing with standard 5000ms default via web-first assertions.
