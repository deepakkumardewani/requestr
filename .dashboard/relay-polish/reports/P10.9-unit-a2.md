- **Fix**: Rewrote test logic to:
  1. Iterate over `CAPABILITY_ACTIONS` instead of individual tools (since actions have multiple tools)
  2. For each action and mode, compute the STRICTEST badge among all tools in the action
  3. Assert `expect(capabilityBadge(action.tools, mode)).toBe(expectedBadge)` — strict equality matching the live approval rules

**Reasoning**: `capabilityBadge()` returns the strictest badge among all tools in an action (ask > asksBulk > runs). The old test tried to check individual tools against multi-tool action badges, creating a mismatch. The fix ensures we validate that the badge computation correctly reflects the approval rules for the complete set of tools in each action.
