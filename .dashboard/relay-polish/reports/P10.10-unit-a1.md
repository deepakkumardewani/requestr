### RelayHeader.tsx - Line 78 (1 branch)
```javascript
if (!cancelled) setTitle(thread?.title ?? null);
```

**Justification**: This branch represents a rare race condition where:
1. A thread loads successfully
2. The component unmounts (setting `cancelled = true`) 
3. The async callback executes after unmount

This is defensive programming to prevent state updates on unmounted components. The happy path (component stays mounted) is fully tested. The edge case is impractical to trigger reliably in unit tests without artificial delays.

**Classification**: Justified uncovered branch (defensive race condition handling)
