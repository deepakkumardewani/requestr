## Key Design Decisions

1. **Clamping semantics**: When viewport resizes, width stays within new [min, max] range; doesn't auto-adjust to 30vw at new viewport (matches app behavior from useClampDockWidthOnResize hook in RelayRoot.tsx).

2. **Sheet variant detection**: Uses `pressRelayShortcut()` helper (platform-aware: Cmd+I on Mac, Ctrl+Shift+L elsewhere) instead of checking toggle visibility, avoiding mobile sidebar visibility issues.

3. **Mobile sheet assertion**: Verifies resize handle is hidden (not rendered) on sheets, rather than trying to drag it.

4. **Body padding assertion**: Uses `page.evaluate()` to read computed `paddingRight` (respects CSS `clamp()`), confirming app uses `--relay-dock-offset` CSS variable correctly.

5. **Viewport resize wait**: Added 100ms delay after `setViewportSize` to allow resize event listeners to fire before assertion.
