# Phase 3.5 "Dock width limits" E2E verification (attempt a3)

VERDICT: PASS

**All 27 tests pass cleanly with --repeat-each=3 (0 flakes). All scenario IDs verified as consistent.**

## Fixes Applied

### 1. Screenshot Theme Fix (snapTaskRequired)
- **Issue**: Screenshots were hardcoded with `-light` suffix but never switched theme to light; images appeared dark
- **Fix**: Added `page.evaluate()` to remove "dark" class and add "light" class before `snapTaskRequired()` captures
- **Verification**: p3-dock-{1440,900,1100,780,320}-light.png now render with light theme (light backgrounds, light sidebars)

### 2. PANEL-02: Fresh Load at 900px
- **Issue**: Spec never loaded fresh at 900px to test default clamping to 320px floor
- **Fix**: Added explicit fresh load at 900px with `page.goto(WORKSPACE_PATH)` and `openRelay()`, asserting MIN_WIDTH_PX (320px)
- **State Management**: Added `closeRelay()` calls before navigation to prevent focus/state issues on subsequent loads

### 3. PANEL-02 Gherkin Corrections (L22-28)
- **Issue**: Lines 25-26 incorrectly described behavior as "makes dock 270px...exactly 320px" when spec keeps 330px on resize
- **Fix**: Rewrote to clearly distinguish:
  - "a fresh load at 900x900 with no saved width opens at 320px (30vw=270px, clamped to floor)"
  - "resizing from 1100px to 900px keeps dock at 330px (still in range [320, 360])"
  - "dragging handle to left edge at 900px makes it 320px (minimum)"

### 4. PANEL-03 Gherkin Drag Direction Fix (L35, L38)
- **Issue**: Gherkin had directions reversed ("drag far right" for max, "far left" for min)
- **Fix**: Corrected to match spec implementation:
  - "drag far to the left" → 576px max (spec drags to clientX 0)
  - "drag far to the right" → 432px min (spec drags to viewport.width)

### 5. PANEL-06 BoundingBox Assertions
- **Issue**: Bbox check had hollow `if (dockBox && contentBox)` guard; used `page.locator("main").first()` instead of test id
- **Fix**: 
  - Added explicit `expect(dockBox).not.toBeNull()` and `expect(contentBox).not.toBeNull()` assertions
  - Replaced `page.locator("main").first()` with `page.getByRole("main")` (web-first approach)
  - Comparison now always runs (not skipped if boxes are null)

### 6. PANEL-09 Context Isolation Removal
- **Issue**: Empty string test ran on separate `page.context().browser()?.newContext()`, bypassing consoleGuard and seeded fixtures
- **Fix**:
  - Stayed on `seededPage` for both "abc" and "" cases
  - Replaced separate context creation with: `page.evaluate((key) => localStorage.setItem(key, ""))` + `page.reload()`
  - Added `closeRelay()` before reload to prevent state issues
  - Removed try/finally pattern (no longer needed without extra context)
  - Fixed snap capture to use correct page reference
